# Steelman + Double-Crux

Two closely related techniques. Use steelman solo. Use double-crux when two parties disagree.

## Steelman

Build the *strongest* version of the view you disagree with. Not the softened version — the version a smart, informed, good-faith advocate would defend.

### Protocol

1. **State the opposing claim** in its own words, as charitably as possible.
2. **Ask: what would a smart advocate add?** — supporting evidence, priors, historical precedent, value frames.
3. **Remove the weakest 20%** — the bits that are rhetorical rather than load-bearing.
4. **Write the steelman** as a 3–5 sentence paragraph with the advocate's strongest argument.
5. **Identify the single sentence in the steelman you find hardest to rebut.**

### Anti-patterns

- **Straw-steel:** softening the opposing view so it's easier to handle. If your steelman is easier to beat than the original, you cheated.
- **Kitchen sink:** including every argument. A steelman is the *best* version, not the full version.
- **Steelmanning to look fair.** The point is to improve your own thinking, not to perform balance.

## Double-crux (Rationalist / Duncan A. Sabien)

When two parties disagree and are stuck, find a single sub-question whose answer would change *both* minds.

### Protocol

1. Each party states their position and *why* — the one or two load-bearing beliefs behind it.
2. Each party lists beliefs they hold that, *if shown false*, would flip their position.
3. Find overlap: a belief both parties agree is load-bearing, but disagree about.
4. That's the **double-crux**. Argue about it, not the surface disagreement.
5. If no overlap exists, the disagreement is about values, not facts — name that and stop arguing.

### Example

Surface disagreement: "We should rewrite service X in Rust."
- A's crux: *if* Rust's maintenance cost over 3 years is lower than the current stack, rewrite; else, don't.
- B's crux: *if* the current stack has a hiring pipeline we can sustain, don't rewrite; else, do.
- Double-crux: "Can we hire maintainers at the current rate for the existing stack for 3 years?"

Suddenly the argument is answerable with data.

### Anti-patterns

- **Infinite-regress cruxes.** If you can't find a crux in 10 minutes, the disagreement is values-based or one party isn't engaging. Say so.
- **Fake cruxes.** A crux you wouldn't actually update on is not a crux. Stress-test: "If I were shown this is true, would I switch?"
- **Attacking motives.** Double-crux only works with good-faith disagreement. Bad-faith is a different problem.
