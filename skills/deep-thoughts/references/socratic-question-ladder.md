# Socratic Question Ladder

Four rungs, climbed in order. Each rung generates questions that **you (the agent) ask yourself**, not the user. The user sees the synthesis, not the interrogation.

## Rung 1 — Clarification

Goal: make sure you understand what is actually being asked.

- What exactly does the user mean by `<key term>`?
- What would an answer look like if it were perfect?
- What's the decision, by whom, by when, reversible or not?
- Is this a *thinking* problem (criteria unclear) or an *execution* problem (criteria clear)?

## Rung 2 — Probe the assumptions

Goal: surface what is being taken for granted.

- What has to be true for this question to even make sense?
- What would change if the opposite were true?
- Whose interests does the current framing favor?
- What is being treated as fixed that is actually negotiable?

## Rung 3 — Evidence

Goal: force claims onto the table.

- What is the strongest evidence *for* the current view?
- What is the strongest evidence *against*?
- What would a disinterested expert say?
- What has not been measured that could be?

## Rung 4 — Implications & consequences

Goal: run the answer forward.

- If this decision is right, what follows in 1 week / 6 months / 3 years?
- What second-order effects are we ignoring?
- Who is harmed if this is wrong, and how badly?
- What is the cheapest experiment that would falsify the plan?

## Synthesis, not interrogation

Run the ladder silently. Produce:

1. The sharpest single reformulation of the question.
2. The 2–3 load-bearing assumptions surfaced.
3. The 1–2 pieces of evidence that would most change the answer.
4. The 1–2 consequences the user may not have considered.

Ask the user at most 3 clarifying questions — only when a rung's answer is blocking.
