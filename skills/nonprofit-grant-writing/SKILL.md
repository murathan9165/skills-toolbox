# Nonprofit Grant Writing

## Overview

Grant proposals fail when agents invent data, confuse outputs with outcomes, or write without reading the funder's actual priorities. This skill enforces the correct sequence: **research first → data collection second → writing third.**

**Iron law: Never draft a section without the underlying data in hand. Ask the user if anything below is unknown.**

---

## Step 0: Pre-Writing Checklist (REQUIRED before any prose)

Stop and verify all of these before writing a single word:

- [ ] Funder's **current** strategic plan or stated priority areas (read it — don't assume)
- [ ] Funder's application format (online portal with character limits? free narrative? LOI first?)
- [ ] Typical grant award size for this funder (check their 990 or website)
- [ ] Organization's **actual** historical data: people served, outcomes achieved, annual budget
- [ ] Organization's prior relationship with this funder — **is this a renewal or first-time application?** (renewal = reference prior performance; first-time = build credibility from scratch)
- [ ] **Local** county-level data for the needs statement (not national generalizations)
- [ ] Whether similar services already exist locally (avoid duplicating funded programs)
- [ ] Any confirmed matching/leveraged funding to show alongside this request

**If any of these are unknown, ask the user before writing.**

## Section Structure

### 1. Executive Summary (150–250 words)
- Who is asking + for what + how much + for whom + what specific outcome
- Name the funder's priority area this directly addresses (use their language)
- Lead with impact: the number of people and the measurable change

### 2. Statement of Need
**Every statistic must be local and sourced. National stats are filler.**
- Use county-level data: eviction rates, shelter utilization, waitlist lengths, PIT counts
- Name the specific gap this program fills — not just "the problem exists"
- Include demographics of the population affected
- Include community voice: a quote from a client, community partner, or needs assessment

### 3. Program Description
- Target population (specific demographics, not "vulnerable people")
- Activities (what staff actually do, frequency, dosage)
- Staffing (FTE, qualifications, new vs. existing position)
- Partner organizations and referral relationships
- Tools and assessments used — note any known controversies (e.g., VI-SPDAT racial bias)

### 4. Goals, Objectives, and Outcomes

**The most common failure point.** Use this hierarchy strictly — never present outputs as outcomes:

| Level | Definition | Example |
|---|---|---|
| **Input** | Resources invested | $60,000, 1.0 FTE Housing Advocate |
| **Activity** | What staff do | Weekly case management sessions |
| **Output** | Countable service units | 120 individuals enrolled |
| **Short-term outcome** | Change in knowledge/skill/behavior | 90% complete a housing application |
| **Long-term outcome** | Change in condition | 45 individuals in stable housing at 6 months |

Set targets at 90–110% of prior year actuals. If no prior data exists, state that explicitly and explain how the target was derived.

### 5. Evaluation Plan
- How data is collected (HMIS, surveys, follow-up calls) and who collects it
- Baseline comparison point (prior year data or sector benchmark)
- Mid-year check: what triggers a program adjustment?
- 6-month and 12-month follow-up plan for outcome retention

### 6. Organizational Capacity
- Years operating, annual budget size
- Prior grant management experience (name 2–3 specific funders)
- Relevant certifications or system memberships (CoC, coordinated entry, HMIS access)
- Staff qualifications specific to this program

### 7. Budget
- Every line item derives from program activities — no padding
- Benchmark salaries to local nonprofit sector data (not guesses)
- Show leverage: list confirmed or pending funding sources with amounts
- Request client direct assistance explicitly with rationale; never claim it is "externally covered" without naming the confirmed source
- Know the funder's indirect rate cap before applying it (United Way affiliates often cap at 10–15%)

**Budget narrative:** One sentence per line item explaining the basis for the number.

### 8. Sustainability
Must be specific — not aspirational.

| Weak | Strong |
|---|---|
| "We will seek additional grants." | "We have submitted a parallel request to [Foundation] for $25,000 and will apply to Ohio ESG in October 2026." |
| "We plan to explore Medicaid billing." | "Our ED met with an Ohio Medicaid consultant in Q1 2026; billing eligibility is confirmed pending licensure." |

### 9. Community Alignment
- Quote the funder's own language from their current strategic plan
- Name the specific pillar/goal this program advances
- Quantify the leverage: "Your $60,000 will leverage $40,000 in confirmed co-funding"

## Equity Checklist (required for 2024+ funders)

- [ ] Demographic breakdown of the population served
- [ ] How program design incorporated client or community voice
- [ ] Whether staff reflect the community being served
- [ ] How the program addresses root causes, not just symptoms

## Funder-Specific Notes

### United Way (community affiliates)
- Typical range: $5,000–$75,000 per program (varies by affiliate annual campaign size)
- Annual community investment cycle with a defined RFP window — confirm dates before writing
- Often use an **online portal with character limits** — do not write a free narrative before confirming the format
- Value: demonstrated local need, alignment with their stated pillars, organizational track record, leveraged funding, coordination with existing services
- Require: quarterly data reports, annual narrative report, participation in learning events
- First-time applicants: establish a relationship with the program officer before submitting

### Private Foundations
- Pull their Form 990 (Schedule I) to see past grantees and typical award sizes before applying
- Most have an LOI (letter of inquiry) stage before a full proposal
- Logic Model or Theory of Change diagram often required

### Government Grants (HUD, FEMA, CDBG, ESG)
- Strict format compliance — deviations disqualify
- Matching funds often mandatory (confirm percentage)
- Much longer timelines: 6–12 months from application to award
- HUD-funded programs must integrate with coordinated entry

## Common Mistakes

| Mistake | Fix |
|---|---|
| Inventing targets without org data | Pull prior year actuals first; set at 90–110% |
| "We serve vulnerable populations" | Name the population with demographics |
| Citing VI-SPDAT without qualification | Note if the local CoC has moved to a different tool |
| $0 for client direct assistance | Request it with rationale, or name the confirmed external source |
| Sustainability = "we'll apply for grants" | Name specific funders, amounts, and timelines |
| Outputs presented as outcomes | Use the Input→Activity→Output→Outcome table above |
| Writing before reading funder priorities | Always read the current strategic plan or RFP first |
| National stats in the needs section | Replace with county-level sourced data |
| Budget numbers guessed | Benchmark every figure; document the source |

---

## Pre-Submission Checklist

- [ ] Every statistic has a local source cited
- [ ] Targets derived from org's actual historical data
- [ ] Budget figures benchmarked, not guessed
- [ ] Outputs and outcomes are clearly distinct
- [ ] Funder's priority language appears verbatim at least once
- [ ] Leverage/match is quantified with confirmed sources
- [ ] Equity framing present (demographics, community voice)
- [ ] Sustainability plan names specific funders/programs with amounts
- [ ] Application format confirmed (portal vs. narrative, page/word limits)
- [ ] Prior relationship with funder addressed in strategy
